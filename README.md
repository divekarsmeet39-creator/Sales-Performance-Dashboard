# Task 4 – Sales Performance Dashboard

## Project Overview
This project is part of my Data Analyst Internship – Task 4: Dashboard Development.

The aim of this project is to design and develop an interactive Sales Performance Dashboard using **Microsoft Power BI**. It provides a clear overview of sales trends, regional performance, product categories, and sales representative contributions.

## Objectives
- Monitor overall business sales performance.
- Track key performance indicators (KPIs).
- Compare sales across different regions.
- Identify top-performing product categories.
- Analyze individual sales representative performance.
- Build an interactive dashboard with slicers and filters.

## Tools & Technologies
- Microsoft Power BI Desktop
- Microsoft Excel / CSV
- DAX (Data Analysis Expressions)
- GitHub

## Dataset Description
**Dataset:** `sales_data.csv`

The dataset consists of 1,000 records and 14 columns containing sales-related information.

Key columns include:
- Product_ID
- Sale_Date
- Sales_Rep
- Region
- Sales_Amount
- Quantity_Sold
- Product_Category
- Unit_Cost
- Unit_Price
- Customer_Type
- Discount
- Payment_Method
- Sales_Channel
- Region_and_Sales_Rep

## Key Performance Indicators (KPIs)
The dashboard displays the following KPIs:

1. Total Sales
2. Total Quantity Sold
3. Total Orders
4. Average Sales
5. Average Discount

## Dashboard Visualizations
The dashboard uses different charts to present sales information:

- **Monthly Sales Analysis:** Displays monthly sales trends and changes over time.
- **Regional Sales Analysis:** Compares sales performance across various regions.
- **Category-wise Sales:** Highlights the sales contribution of different product categories.
- **Sales Representative Analysis:** Evaluates and compares the performance of sales representatives.

## Interactive Filters
The dashboard provides interactive slicers for:
- Region
- Product Category
- Sales Representative
- Customer Type
- Sales Channel

These filters make it easier to view specific data and perform detailed sales analysis.

## Key Insights
- The North region contributes the highest sales.
- Clothing is the leading product category in terms of sales.
- Sales representatives can be evaluated based on their individual contributions.
- Interactive visualizations make it easier to identify sales patterns and trends.

## How to Run
1. Download or clone the project repository from GitHub.
2. Install and open Microsoft Power BI Desktop.
3. Open the `Task4_Sales_Dashboard.pbix` file.
4. Update the CSV file path if Power BI requests the dataset location.
5. Use the dashboard slicers and filters to explore the sales data.

## Conclusion
This project helped demonstrate the use of Power BI for sales analysis and dashboard development. By converting raw data into interactive visual reports, the dashboard provides useful insights into business performance, regional sales, and product categories, supporting informed decision-making.
